# Veilbound Arcana — Frontend Web Application

> **Mandatory Disclaimer:** *This project is experimental confidential software. Use at your own risk.*

Next.js / React Web Application for Veilbound Arcana featuring:
- **1-Signature Decryption Session:** Sign once to decrypt sealed cards and private hands locally.
- **Ritual Gacha (Framer Motion):** Mystical 3D face-down Tarot card flip and instant Unseal activation.
- **Duel Arena (Bluffing UI):** Secret hand view, confidential energy allocation dial, round commit & reveal animations.
- **Deck Builder:** 5-card deck builder with live cost and duplicate constraint validators.
- **Verify Page:** Direct on-chain proof inspection, transaction explorer links, and fairness odds verification.

## Development

```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.
